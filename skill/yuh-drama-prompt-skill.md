## 技能正文

【定位】本技能是选装增强，与出厂技能并行、不替代：日常做剧默认走出厂流程；小说改编多镜连续剧（有道具/光线/台词/服装连续性要求）时调取本技能。本技能只约束「分镜创作、提示词内容与检查动作」，绝不改动画布节点、连线、全自动做剧流程结构。

【第一部分·标准流程（继承出厂已验证流程，原样执行）】
1. 输入三件套：人物三视图素材、场景素材、音色素材；禁止生成多余的独立音频文件
2. 视频风格统一 2.5D 动漫；台词直接作为视频音轨输出，不使用独立旁白
3. 音色素材节点必须先 run 出 wav，视频节点 prompt 里引用 `<Audio N>` 才能过软件校验（否则报「需要 N 个独立音色参考，当前只连入 0 个」）
4. 多镜逐镜续接（尾帧三步法）：上镜 run 完→提取尾帧（单独一批发）→从 canvas-projects.json 定位新节点→disconnect 下镜全部图片线→单发 connect 尾帧→批量补角色线→run
5. 提示词存放在 canvas-projects.json 的 text 字段；用 canvas_update 改视频/图片节点提示词必须传 prompt 字段（传 text 会被静默丢弃且不报错，run 后才发现还是旧词）
6. run 假失败处理：canvas_run 约 10 分钟报 REQUEST_TIMEOUT 属假失败（任务实际已在跑），立即 list_tasks 找最新任务 id 用 task_wait 等结果，禁止盲目重跑（会双跑）
7. 多镜成片必须用画布自带自动剪辑通道拼接：yuh_studio_call('utilities:merge-videos', {files:[按镜序的mp4绝对路径], outputDir:'<输出根>\Canvas\DramaRoughCut', transition:'none'})；拼完 canvas_add 建 video 节点（标题「拼合预览（N 段）」）→ canvas_update 挂 media_path → 把 N 个分镜节点 connect 进该节点；禁止用 ffmpeg 自行拼接

【第二部分·小说→分镜脚本创作规范（输入是小说时，智能体分析定分镜/环境/风格必须遵守）】
1. 一镜只一个角色开口：模型多人同框是弱项、口型只能对一个说话人——需要对话就切镜（正反打，A 说完切 B 单人镜），多人同框镜头只做静态群像不安排台词；同框的其他角色提示词必须写明闭唇静止
2. 场景色温/光源逐场景锁定：分镜阶段为每个场景写死「时段+光源+色温」（如：深夜室内、单一油灯暖光侧逆光、全片该场景不变），之后每镜提示词照抄；禁止随剧情心境乱改光线（冷暖跳变=穿帮）
3. 风格与造型锁定：2.5D 动漫风 + 每个角色的造型规范（服装/发型/年龄感）分镜阶段定稿成一段固定英文描述，每镜提示词逐字照抄，禁止每镜换说法（模型看文字比看参考图更当真，说法不统一=造型漂移）
4. 道具登记表：分镜阶段列出全片道具清单（形状/材质/颜色/数量/状态），每镜用到的道具照表描述；新道具首次出现必须有引入镜头（先写「把照片放进纸箱」再写「抱着纸箱」）
5. 场景布局锁定：场景内家具/陈设/方位分镜阶段写死（桌是圆是方、门朝哪开），每镜照抄，禁止即兴
6. 镜头时长不拍脑袋：按「台词字数÷4-5字/秒 + 开口缓冲 + ≥1.3秒活尾」估算，宁长勿短；帧数有格子（填 6 秒给 6.58、填 7 秒给 7.29），按实际输出秒数排时间轴
7. 分镜尽量落强项：一人独处/冷调侧光/一句台词/固定机位/物件特写是强项；群戏、打斗改成切单人反应镜或物件特写镜来叙事

【第三部分·run 前提示词审查四步法（每镜必过；不过审先改词再审，禁止直接 run）】
①常理/逻辑审查：画面符合物理常识与剧情逻辑——雨天无月光、关灯后光源必须有来源、道具不凭空出现/消失/变形、同一人不同时两地
②道具特意约束审查：可交互道具显式写死形状/材质/颜色/数量/状态，禁止泛称（a table/a box 会被模型自由发挥，实测圆桌方桌前后镜不一致翻车）
③H3 官方模板合规审查：三段式完整（时间轴正文/overall_soundscape/non_diegetic_music: N/A）；`<Picture N>`/`<Audio N>` 编号逐一对 canvas-projects.json 连线顺序核；台词官方句式（(S1)/(S2) 说话人ID全片一致；画外音固定短语 off-screen voiceover + lips remain completely closed；`<d>[Chinese]台词</d>`）；中文台词 4-5 字/秒给足窗口；正文全英文不夹中文；Continuity anchor 英文置顶；禁空泛词（cinematic/beautiful 等）
④连续性六项链逐镜核对：时间光线链/道具链/场景家具形状链/服装链/人数站位链/动作承接链（下镜起始态=上镜末态）；多镜 soundscape 统一（如全片持续雨声）

【第四部分·H3 局限与避坑（外部 35-40 小时实测复盘得来，提前规避）】
1. 能力区窄：擅长=一人独处、冷调侧光、一句台词、固定机位、物件特写；弱项=多人同框、打斗、暖黄光下的人脸、易变形小道具。分镜尽量落强项；避不开弱项时用第三部分审查死守
2. 光线是最大变量：人脸镜头优先冷调侧光（明暗轮廓反差大，放大后才有细节可依）；必须暖光时把主光压成侧逆光靠轮廓制造反差；同一场景全片光线一致
3. 道具会被自由发挥（半块玉佩能画成一团红）：所有道具特征写死，特写镜头尤其要写
4. 台词时间轴不可控：开口时刻 0-6 秒随机、语速 1-6 字/秒波动——台词按 4-5 字/秒给足窗口，并在提示词写明「说完台词后至少留 1.3 秒再结束（活尾）」，不把镜头时长卡死
5. 复读风险：台词简短明确，避免长否定句（实测「没有敲门也没有回答」被念成「没有敲门，没有敲门也没有回答」）
6. 文字比参考图更被模型当真：提示词必须与人物造型规范完全一致，禁止双源矛盾（一处英文写反，错误会跟着模板复制到后面每一镜）
7. 尾帧接尾帧取干净帧：别用最后一帧（末尾常已漂移），往前退几帧取
8. 帧数格子：填 6 秒实际给 6.58 秒、填 7 秒给 7.29 秒（可用帧数有格子、向上取整），时间轴按实际输出秒数排，不按填写秒数
9. 机器不能自判无误：自动流程的报错/红灯必须停下人工核实再续跑，禁止自动清错后继续跑（实测废品率 62%）
10. 排产单位是一场戏、不是固定时长：一场戏 3-12 个镜头由内容决定；每镜等长会让成片像预告片（每镜差不多长+每镜一句台词=预告片语法）

【大白话总结】出厂的照旧跑，这本手册用时才掏出来：小说先按第二部分拆分镜（一人一镜说话、色温风格道具全锁定）→ 提示词按第三部分四步审查改到过审 → 过审再 run → 跑完按六项链逐镜对一遍 → 最后走画布自带拼接收尾。坑全是别人真金白银烧出来的，照着躲就行。
