# YUH 画布 · 全自动做剧提示词技能（选装）

> 给 YUH Studio 画布助手（小黑）用的**选装技能**。本质是一套提示词技能：覆盖「小说 → 分镜 → 提示词 → 审查 → run → 拼片」全链路的创作规范与避坑规则。
>
> **双仓互备**：GitHub 与腾讯云 CNB 各一份，内容完全一致，任一处网页可改。

---

## 一、这是什么

YUH Studio 的画布助手（小黑）自带出厂技能。我们**不改动任何出厂内容**，而是把实战验证过的做剧经验整理成一个独立的自定义技能，通过画布自带的「添加 Skill」功能加入：

| 设计原则 | 说明 |
|---|---|
| **出厂不动** | 出厂技能库、小黑记忆文件，一个字不改 |
| **只增不改** | 我们的经验全部装在这一个选装技能里，与出厂技能并存 |
| **选装调用** | 用时在技能下拉里勾选它才生效；不用时完全不参与 |
| **随时可退** | 不想要了在画布技能列表里删掉即可，出厂从未被碰过 |

## 二、技能内容总览（四部分）

技能名：**《全自动做剧·流程审查与避坑手册（选装）》**

| 部分 | 内容 | 条数 |
|---|---|---|
| 一·标准流程 | 出厂已实战验证的流程原样继承：三件套输入、音色先出 wav、尾帧续接三步法、改词传 prompt 字段、run 假失败处理、画布自带拼接 | 7 条 |
| 二·小说→分镜创作规范 | 输入是小说时，智能体分析定分镜/环境/风格必须遵守：**一镜只一人开口**+正反打切镜、场景色温光源逐场景锁定、造型规范英文逐字照抄、道具登记表+引入镜头、场景布局锁定、镜头时长按台词字数估算、分镜落强项 | 7 条 |
| 三·run 前审查四步法 | ①常理/逻辑（雨天无月光、道具不凭空出现）②道具特意约束（形状/材质/颜色/数量写死，禁止泛称）③H3 官方模板合规（三段式、`<Picture N>`/`<Audio N>` 编号、`(S1)/(S2)` 台词句式、4-5 字/秒给足窗口）④连续性六项链（时间光线/道具/场景家具/服装/人数站位/动作承接） | 4 步 |
| 四·H3 局限避坑 | 外部 35-40 小时实测复盘得来：能力区窄、光才是最大变量、道具自由发挥、台词时间轴失控、复读、文字比参考图更当真、尾帧取干净帧、帧数格子、红灯必须真停、排产单位是一场戏 | 10 条 |

技能全文见 [`skill/yuh-drama-prompt-skill.md`](skill/yuh-drama-prompt-skill.md)。

## 三、怎么用（画布内）

1. 打开 YUH Studio → 画布对话界面 → 技能下拉
2. 找到 **《全自动做剧·流程审查与避坑手册（选装）》** 勾选
3. 勾选后小黑每轮对话自动带上这套规范；取消勾选则完全恢复出厂行为
4. 日常简单任务不用勾；**小说改编多镜连续剧建议勾上**

## 四、怎么更新这个技能

改完仓库后，把新内容同步进画布（两种方式任选）：

- **让助手改**：对助手说「把 skill/yuh-drama-prompt-skill.md 的内容同名覆盖到选装技能」→ 助手调用画布 save_skill 接口同名覆盖
- **自己改**：YUH Studio 技能管理界面 → 找到该技能 → 编辑粘贴全文保存
